About

What is Pegasus Pages?

Pegasus Pages is a server-side page framework for Delphi inspired by ASP.NET Razor Pages and Next.js. It brings file-based routing, a template engine with automatic encoding, nested layouts, and reusable components to the Delphi ecosystem.

How it works

Drop a page.html file in a folder and it becomes a route. Create a PageModel class to handle GET/POST logic. Use layouts for shared structure and components for reusable UI blocks.

pages/
  _layout.html     // root layout with html/head
  page.html        // route: /
  about/
    page.html      // route: /about
  blog/[id]/
    page.html      // route: /blog/:id

Template Syntax

Simple, familiar expressions with safe defaults:

<h1>{{raw title}}</h1>          // raw output (trusted)
<p>{{message}}</p>             // html-encoded
{{if logged}}                  // conditionals
{{for item in items}}          // loops
{{partial _header}}            // partials
{{price | currency:'prefix'}}  // filters
